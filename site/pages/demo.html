A dark section in any theme

data-kern-theme="dark" on this section switches KERN's tokens here only. The token utilities follow because @theme inline compiles them to KERN's variables.

A light section in any theme

data-kern-theme="light" keeps this section light on a dark page. KERN's components and the token utilities follow it. The palette button's dark: pair doesn't: on a dark page it still matches here, as Limits explains, so it keeps its dark colours.
